# Colour font fixture

samples-sbix.ttf is the unmodified 19,608-byte sample bitmap font from googlefonts/color-fonts, commit 0046ea4c3b69e9fbbe464c2594816894e3aa5e4b.

Source: https://github.com/googlefonts/color-fonts/blob/0046ea4c3b69e9fbbe464c2594816894e3aa5e4b/fonts/samples-sbix.ttf

SHA-256: 0fd0a23379b0e982db8bef5f9a50cf7960a6ee3504778a9a9c039bde4d2f573d

The repository uses Apache License 2.0; its unmodified license accompanies this fixture as Google-color-fonts-LICENSE.txt. The `simple_linear` ligature selects a coloured gradient bitmap. Tests load the file through a private DirectWrite collection; no system fonts are installed or changed.
